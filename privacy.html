写真・動画

本ソフトは、写真・動画をインターネット（クラウド）に送りません。すべて、お使いのパソコンと、選んだ保存先（PC・外付けHDD・NAS）の中で扱います。

インターネットの利用

本ソフトは、インターネットに何も送りません。地図も、本ソフトに入っている地図のデータ（Natural Earth）で表示します。

ただし、お試し版か製品版かを確かめるため、Windows が Microsoft Store（Microsoft）と通信することがあります。また、アプリの更新は Microsoft Store の仕組みで行います（本ソフト自身は問い合わせません）。

🔒 人に見せたくないかもしれない写真の判定も、パソコンの中だけで行い、どこにも送りません。

パソコンや保存先に残るもの

  • タグ・履歴など：保存先の「Family Shelf」の中（.family-shelf フォルダ）
  • 縮小画像などの控え：このパソコンの Microsoft Edge の中

保存先をNASなどで共有すると、上の記録もほかの人から見えます。

利用状況の送信

本ソフトは、使い方の記録や個人の情報を販売者に送りません。

購入とお支払い

本ソフトの購入・お支払いは Microsoft Store で行われ、その情報は Microsoft が扱います（Microsoft のプライバシーに関する声明が適用されます）。販売者は、お客様のお名前やお支払いの情報を受け取りません。

Windows の設定によっては、本ソフトが異常終了したときなどの情報を Windows が Microsoft に送ります。販売者は、そのうち本ソフトに関するもの（個人を特定できない形）を、不具合を直すために見ることがあります。
